## Timings

- Performance test (1 car + 20 dynamic boxes, 600 steps): 191-224 ms across runs (0.32-0.37 ms/step); bound is 2000 ms.

## Determinism

- 30 s scripted run (throttle, steering, handbrake as pure functions of the tick): hashes at every second equal across two runs in one process.
- Hashes compared with `test/fixtures/determinism.json`, generated by `bun run fixture:determinism` under Bun and read under Vitest on Node, so the match crosses processes and JS engines.
- Snapshot at tick 600, run 300 more ticks, restore, rebuild controller from the `CarSpec`, continue to tick 1200: hashes equal the uninterrupted run at every second (exact, no tolerance needed).
