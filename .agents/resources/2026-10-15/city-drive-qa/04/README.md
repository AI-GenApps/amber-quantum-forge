# Task 04: CC0 asset pipeline evidence

Date: 2026-10-15. Source: Kenney City Kit (Roads, Commercial, Suburban) and Car Kit, all CC0.
No other source was used (no Quaternius, no Sketchfab).

## Result

- 42 models, **2,470,860 bytes (2.36 MB) of an 8 MB budget**, shipped as
  **uncompressed GLB** (dry-run amendment: default to uncompressed). No Draco, no meshopt, so no
  decoder is shipped and nothing points at a CDN
  (`grep -rn "cdn.babylonjs.com" apps-games/city-drive/src` is empty, and a test checks it).
- Pipeline per model (`apps-games/city-drive/scripts/build-assets.ts`, library
  `@gltf-transform/*` 4.5.1, `sharp` 0.35.3, all exact-pinned): `dedup`, `prune`, `weld`, texture
  resize to at most 512 px (the Kenney colormaps are already 512x512), write GLB with the
  texture embedded.
- Triangle counts are per node instance (dedup shares one wheel mesh between four wheel nodes).
- Budgets and caps: machine-readable totals in `budget-report.json` (this folder).
  The largest building is 2,544 triangles (cap 3,000), the largest car 2,474 (cap 5,000), the
  largest road tile 260 (cap 500).
- Idempotent: running `build-assets` a second time rewrote byte-identical files (sha256 of every
  file under `public/assets` and `assets-src/LICENSES` compared before and after).
- All 42 outputs pass `gltf-transform validate` (`build-assets --raw <dir> --validate`).
- `build-assets` without the gitignored `assets-src/raw/` only verifies the committed manifest,
  budgets and licence records, so a fresh checkout can still run it.

## Manifest schema

`apps-games/city-drive/public/assets/manifest.json`, generated by the build script:

```json
{ "schemaVersion": 1, "models": [ {
  "id": "car-sedan", "file": "models/car-sedan.glb", "kind": "car",
  "triangles": 2032, "bytes": 72984,
  "bbox": { "min": {"x":-0.75,"y":0,"z":-1.3}, "max": {"x":0.75,"y":1.3,"z":1.25} },
  "pack": "car-kit", "licence": "car-kit" } ] }
```

`file` is relative to `public/assets`; `licence` equals the pack id of a record in
`assets-src/LICENSES/`. Types, id patterns and budgets live in
`apps-games/city-drive/src/assets/manifest.ts`.

Fixed id scheme (later tasks reference these literally):

- roads: `road-straight`, `road-corner`, `road-t`, `road-crossroads`, `road-end`, `road-crossing`
- buildings: `bld-<kit>-<name>` with kit `commercial` or `suburban`
- props: `prop-<name>`
- cars: `car-<name>`
