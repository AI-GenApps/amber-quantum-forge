# 05 — TypeScript → Swift codegen script

## Goal
Create `scripts/codegen-swift.ts` that reads shared TypeScript sources and generates Swift files into `apps-native/ios-app/Starter/Generated/`, keeping mobile and iOS in sync for config keys, analytics events, and design tokens.

## Context
- Sources read by codegen:
  - `packages/api/src/types/config.ts` → `Generated/AppConfigKeys.swift`
  - `packages/analytics/src/events.ts` → `Generated/AnalyticsEvents.swift`
  - `apps/native/components/themed/tokens.ts` → `Generated/DesignTokens.swift`
- Script runs with `bun scripts/codegen-swift.ts`
- Output files must have a header comment: `// Generated by scripts/codegen-swift.ts — DO NOT EDIT`
- Add `codegen-swift` script to root `package.json`
- Add to CI (epic 09) — but for now just the script

## Implementation Checklist
- [ ] Create `scripts/codegen-swift.ts`:
  - Imports: `node:fs`, `node:path` — no external deps
  - Function `generateAppConfigKeys()`: reads `packages/api/src/types/config.ts`, extracts string literal union type `ConfigKey`, emits Swift `enum AppConfigKey: String { case ... }`
  - Function `generateAnalyticsEvents()`: reads `packages/analytics/src/events.ts`, extracts `AnalyticsEvent` discriminated union `type` values, emits Swift `enum AnalyticsEventType: String { case ... }`
  - Function `generateDesignTokens()`: reads `apps/native/components/themed/tokens.ts`, extracts `Colors.light` object, emits Swift `struct DesignTokens { static let light = ColorSet(...) }` with hex string values
  - Each function writes to `apps-native/ios-app/Starter/Generated/<filename>.swift`
  - Main: call all three functions, log `Generated X files`
- [ ] Add to root `package.json` scripts: `"codegen:swift": "bun scripts/codegen-swift.ts"`
- [ ] Run `bun run codegen:swift` and verify generated files are syntactically valid Swift
- [ ] Add `apps-native/ios-app/Starter/Generated/*.swift` patterns to `.gitignore` — NO: generated files SHOULD be committed (so Xcode build doesn't require running script first)
- [ ] Run `bun run check` from repo root — exits 0
