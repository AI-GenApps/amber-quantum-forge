# FAQ

## Do I need to know the internal architecture to use the public docs?

No. These pages focus on the practical steps to run, debug, and support the product.

## Where are internal implementation notes?

Internal docs live at `docs-internal/` and are for contributors and engineers.

## Where is API reference?

Internal API docs include OpenAPI under `docs-internal/openapi/api.yaml`, which also
feeds the internal docs site for reference.
