# Quick Start

Use this for people landing on the repository docs from the public site and
wanting to test the product quickly.

1. Clone and install dependencies:

```bash
git clone <repo-url>
cd starter-expo-mobile
bun install
```

2. Duplicate environment defaults:

```bash
cp .env.example .env
```

3. Start everything:

```bash
bun run dev
```

If the API or frontend does not come up, first check the troubleshooting
section for the exact error text and the component it belongs to.
