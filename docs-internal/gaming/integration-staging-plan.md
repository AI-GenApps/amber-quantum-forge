## Files to stage deliberately

Track the scoped workspace `apps-native/games/pubspec.yaml`, `toolchain.json`, and its single root `pubspec.lock`. Member `pubspec.lock` files are not part of the workspace boundary. Stage each app's Dart source, assets/content, `pubspec.yaml`, `ios/project.yml`, Android/iOS identity/config source, and the intended launcher/splash assets under `android/app/src/main/res/` and `ios/Runner/Assets.xcassets/`. Stage generated plugin registrants only when the app's checked-in native convention requires them and they are reproducible from the checked-in project source.

Leave generated caches and local outputs ignored: `**/.dart_tool/`, `**/build/`, `**/Pods/`, `**/DerivedData/`, `**/ios/Flutter/ephemeral/`, `.flutter-plugins*`, `.packages`, `.pub-cache/`, `**/.gradle/`, `**/local.properties`, local keystores/properties, and temporary APK/IPA output. The root Pub lock is the intentional generated dependency artifact; per-app locks and build output are not. Existing 243×540 visual evidence under `docs-internal/gaming/evidence/visual/` is historical review documentation, not a substitute for final readable-width device captures or a current device build. Final app-only captures must retain at least 720px width or reasonable original dimensions and be losslessly optimized without content changes.

## Freeze and verification sequence

1. The integration lead freezes root/tooling/app edits and records the exact worktree state. Do not rerun an older snapshot and label it final.
2. Run the pinned Bun bootstrap and gaming checks, then the pure package and affected checks. Run root `check:ci`, typecheck, API tests and Knip only after the root/apps freeze; preserve exact pre-existing environment blockers.
3. Run `bun run check:doc-paths`, the staged-doc path checker and pinned Mintlify validation with `PATH=/tmp/luna-bun-1.3.3/bin:$PATH bun x mintlify validate` from `docs-internal/`. A transient Mintlify `react/jsx-runtime` environment failure must be resolved in the toolchain/cache; do not weaken validation or remove docs from navigation.
4. Android final QA retains the accepted readable smoke captures and per-app route ledger. The postmigration rebuild/install/relaunch pass is complete; unchanged first-three APK hashes are explained by tree-shaken unused migration code. No simulator or emulator result closes this gate.
5. Keep iOS QA paused until after Google Play publication. Verify Play registration, signing, privacy/data-safety, listing, content rating, support, release-track and rollback gates separately from the five MVP ledgers.
