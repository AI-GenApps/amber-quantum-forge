# 13 — Flutter Plugins

Flutter plugins are Dart packages in `plugins/flutter/<plugin-name>/`, path-linked into `apps-native/flutter-app/pubspec.yaml`. This is the Dart analog of `plugins/ios/*` linked via `project.yml`'s `packages:` block.

## Plugin structure

```
plugins/flutter/<plugin-name>/
  pubspec.yaml            # package manifest
  lib/
    <plugin_name>.dart     # barrel export
    src/
      *.dart
  test/                    # optional
```

## Available plugins

| Plugin | Package | Purpose |
|---|---|---|
| auth | `plugins/flutter/auth` (`starter_auth`) | Apple/Google sign-in, secure token storage, two-stage JWT exchange + refresh interceptor |
| ai | `plugins/flutter/ai` (`starter_ai`) | `AISession`, SSE/Vercel data-stream parser, on-device AI stub |
| chat | `plugins/flutter/chat` (`starter_chat`) | Chat UI widgets, local persistence, sync client (depends on `starter_auth` + `starter_ai`) |

## Adding a plugin

1. Create `plugins/flutter/<plugin-name>/pubspec.yaml` with the package definition.

2. Add a path dependency in `apps-native/flutter-app/pubspec.yaml`:

   ```yaml
   dependencies:
     <plugin_name>:
       path: ../../plugins/flutter/<plugin-name>
   ```

3. Resolve dependencies:

   ```bash
   cd apps-native/flutter-app
   flutter pub get
   ```

There is no Flutter equivalent of regenerating an Xcode project — `flutter pub get` is the only step needed after editing `pubspec.yaml`.

## Removing a plugin

1. Remove the dependency entry from `apps-native/flutter-app/pubspec.yaml`.
2. Delete `plugins/flutter/<plugin-name>/`.
3. Run `flutter pub get`.

## Codegen

Shared config keys, analytics event types, and design tokens are generated from a single TypeScript source of truth (`scripts/codegen/registry.ts`) into both Swift and Dart. To regenerate the Dart output in `apps-native/flutter-app/lib/generated/`:

```bash
bun run codegen:dart
```

Generated files are committed (mirrors the iOS `Generated/` directory) and are marked `// Generated by scripts/codegen-dart.ts — DO NOT EDIT`. Run `bun run codegen` to regenerate both Swift and Dart output together.
